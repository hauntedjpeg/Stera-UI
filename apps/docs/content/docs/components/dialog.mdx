## Composition

Use the following composition to build a `Dialog`:

```text
Dialog
├── DialogTrigger
└── DialogContent
    ├── DialogHeader
    │   ├── DialogTitle
    │   └── DialogDescription
    └── DialogFooter
```

## Design

<DesignGuidelines>

### When to use

- Focused, self-contained tasks: creating a record, editing details, reviewing supplementary information.
- Tasks short enough to finish without much scrolling.

### When not to use

- Confirmations. Use an [Alert Dialog](/components/alert-dialog).
- Long or complex content. Use a [Drawer](/components/drawer) or a dedicated page.

### Guidelines

- Give every dialog a clear title and a visible close control, so users never feel trapped.
- Keep footer actions to two at most. If no action is needed, a single close button is enough.
- Your call: where the primary action sits in the footer (left, right, full width). Pick one and use it in every dialog.

See also: [Overlays](/guidelines/choosing-components#overlays).

</DesignGuidelines>

## API Reference

Built on Base UI's [Dialog](https://base-ui.com/react/components/dialog#api-reference) primitive — see the full API reference there.

### DialogPopup

| Prop | Type | Default |
| --- | --- | --- |
| `scroll` | `false \| "content"` | `false` |
| `showCloseButton` | `boolean` | `true` |
| `initialFocus` | `boolean` | `true` |

### DialogFooter

| Prop | Type | Default |
| --- | --- | --- |
| `showCloseButton` | `boolean` | `false` |

### DialogTrigger

| Prop | Type | Description |
| --- | --- | --- |
| `render` | `ReactElement` | Render prop for the trigger element |

### DialogClose

| Prop | Type | Description |
| --- | --- | --- |
| `render` | `ReactElement` | Render prop for the close element |
