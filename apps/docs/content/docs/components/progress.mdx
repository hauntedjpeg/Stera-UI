## Design

<DesignGuidelines>

### When to use

- A process you can measure, such as a file upload, a multi-step form or a background task, where a percentage or value can be tracked over time.

### When not to use

- Waits whose completion can't be measured. Use a [Skeleton](/components/skeleton) or a Spinner.
- Letting users set a value in a range. Progress is read-only. Use a [Slider](/components/slider).

### Guidelines

- Give a progress bar a visible label and value whenever the context doesn't make clear what it measures, such as when several appear on the same surface.

See also: [Loading and empty states](/design/loading) and [Theming](/design/theming).

</DesignGuidelines>

## Composition

Use the following composition to build a `Progress`:

```text
Progress
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

`ProgressTrack` and `ProgressIndicator` are rendered automatically by `Progress`. `ProgressLabel` and `ProgressValue` are optional.

## API Reference

Built on Base UI's [Progress](https://base-ui.com/react/components/progress#api-reference) primitive — see the full API reference there.

### Progress

Built on Base UI's `Progress.Root`. Automatically renders the track and indicator internally.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number \| null` | — |

### ProgressLabel

Renders a descriptive label aligned to the start. Accepts all Base UI `Progress.Label` props.

### ProgressValue

Renders the current percentage value aligned to the end. Accepts all Base UI `Progress.Value` props.

### ProgressTrack

The outer bar container. Accepts all Base UI `Progress.Track` props.

### ProgressIndicator

The inner filled bar. Accepts all Base UI `Progress.Indicator` props.
