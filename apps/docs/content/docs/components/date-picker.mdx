## Composition

Use the following composition to build a `DatePicker`:

```text
DatePicker
├── DatePickerTrigger
└── DatePickerContent
```

`DatePickerContent` renders a [Calendar](/components/calendar) in a [Popover](/components/popover). The value lives on `DatePicker`, so the trigger and the calendar always agree.

## Design

<DesignGuidelines>

### When to use

- Picking a date as part of a form, such as a due date, a start date or a date of birth.
- Picking a start and end date in a form, such as a booking window or a reporting period.

### When not to use

- The dates should stay on the page, such as a booking view or a scheduling sidebar. Use a [Calendar](/components/calendar).

### Guidelines

- Always show a placeholder, such as "Pick a date," so it's clear nothing has been chosen yet.
- When the date is likely to be far from today, such as a birth date, offer a faster way to jump to a month and year than stepping through months one at a time.
- Disable the dates users can't pick.

See also: [Forms](/guidelines/choosing-components#forms).

</DesignGuidelines>

## API Reference

Built from [Calendar](/components/calendar) and [Popover](/components/popover).

### DatePicker

| Prop            | Type                      | Default    |
| --------------- | ------------------------- | ---------- |
| `mode`          | `"single" \| "range"`     | `"single"` |
| `value`         | `Date \| DateRange`       | —          |
| `defaultValue`  | `Date \| DateRange`       | —          |
| `onValueChange` | `(value) => void`         | —          |
| `open`          | `boolean`                 | —          |
| `defaultOpen`   | `boolean`                 | `false`    |
| `onOpenChange`  | `(open: boolean) => void` | —          |
| `disabled`      | `boolean`                 | `false`    |
| `locale`        | `DayPickerLocale`         | —          |

`value` is a `Date` in `single` mode and a `DateRange` in `range` mode. Import locales from `react-day-picker/locale`; the locale sets both the calendar and the trigger's text.

### DatePickerTrigger

| Prop          | Type                                      | Default         |
| ------------- | ----------------------------------------- | --------------- |
| `size`        | `"sm" \| "md" \| "lg"`                    | `"md"`          |
| `placeholder` | `string`                                  | `"Pick a date"` |
| `formatValue` | `(value: Date \| DateRange) => ReactNode` | —               |

By default the trigger shows dates like "Nov 17, 2026" and ranges like "Nov 17 – Nov 23, 2026".

### DatePickerContent

Accepts every [Calendar](/components/calendar#api-reference) prop except `mode`, `selected`, `onSelect` and `required`, plus these:

| Prop         | Type                                     | Default    |
| ------------ | ---------------------------------------- | ---------- |
| `align`      | `"start" \| "center" \| "end"`           | `"start"`  |
| `side`       | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` |
| `sideOffset` | `number`                                 | `4`        |
| `className`  | `string`                                 | —          |

`className` styles the popover. To style the calendar, use `classNames`.
