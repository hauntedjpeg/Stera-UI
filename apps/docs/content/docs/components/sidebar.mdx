## Usage

Wrap your layout with `SidebarProvider` and use `SidebarInset` for the main content area.

```tsx
import { SiHome } from "stera-icons"

import {
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupContent,
  SidebarGroupLabel,
  SidebarInset,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarProvider,
  SidebarTrigger,
} from "@/components/ui/sidebar"
```

```tsx
<SidebarProvider>
  <Sidebar>
    <SidebarContent>
      <SidebarGroup>
        <SidebarGroupLabel>Application</SidebarGroupLabel>
        <SidebarGroupContent>
          <SidebarMenu>
            <SidebarMenuItem>
              <SidebarMenuButton isActive render={<a href="/" />}>
                <SiHome />
                <span>Home</span>
              </SidebarMenuButton>
            </SidebarMenuItem>
          </SidebarMenu>
        </SidebarGroupContent>
      </SidebarGroup>
    </SidebarContent>
  </Sidebar>
  <SidebarInset>
    <header className="flex h-16 items-center gap-2 border-b px-4">
      <SidebarTrigger />
    </header>
    {/* page content */}
  </SidebarInset>
</SidebarProvider>
```

Below 768px the sidebar opens in a [Drawer](/components/drawer) instead, and `SidebarTrigger` opens and closes it. ⌘B (Ctrl+B on Windows and Linux) toggles the sidebar anywhere outside a text field.

## Composition

Use the following composition to build a `Sidebar` layout:

```text
SidebarProvider
├── Sidebar
│   ├── SidebarHeader
│   │   ├── SidebarInput
│   │   └── SidebarMenu
│   │       └── SidebarMenuItem
│   │           └── SidebarMenuButton
│   ├── SidebarSeparator
│   ├── SidebarContent
│   │   └── SidebarGroup
│   │       ├── SidebarGroupLabel
│   │       ├── SidebarGroupAction
│   │       └── SidebarGroupContent
│   │           └── SidebarMenu
│   │               ├── SidebarMenuItem
│   │               │   ├── SidebarMenuButton
│   │               │   ├── SidebarMenuAction
│   │               │   └── SidebarMenuBadge
│   │               ├── SidebarMenuItem
│   │               │   ├── SidebarMenuButton
│   │               │   └── SidebarMenuSub
│   │               │       └── SidebarMenuSubItem
│   │               │           └── SidebarMenuSubButton
│   │               └── SidebarMenuItem
│   │                   └── SidebarMenuSkeleton
│   ├── SidebarFooter
│   └── SidebarRail
└── SidebarInset
    └── SidebarTrigger
```

`SidebarMenuAction` and `SidebarMenuBadge` go after the `SidebarMenuButton` they belong to, since they follow its size.

## Examples

### Collapse to icons

<ComponentPreview name="sidebar-icon" />

`collapsible="icon"` shrinks the sidebar to its icons instead of hiding it. Give each `SidebarMenuButton` a `tooltip`, which shows only while the labels are hidden. `SidebarRail` adds a strip along the edge that toggles the sidebar on click.

### Floating

<ComponentPreview name="sidebar-floating" />

`variant="floating"` detaches the sidebar from the window's edge as a panel of its own.

### Inset

<ComponentPreview name="sidebar-inset" />

`variant="inset"` turns `SidebarInset` into a card next to the sidebar.

### Submenu

<ComponentPreview name="sidebar-submenu" />

Nest a `SidebarMenuSub` inside a `SidebarMenuItem` for child pages. `SidebarMenuSubButton` renders a link by default.

### Actions

<ComponentPreview name="sidebar-actions" />

`SidebarGroupAction` pins a button to a group's label, and `SidebarMenuAction` pins one to a menu item. Set `showOnHover` to reveal the menu action only on hover or focus. It stays visible on touch screens and while its menu is open.

### Badge

<ComponentPreview name="sidebar-with-badge" />

Use `SidebarMenuBadge` to display a count or status indicator next to a menu item.

### Loading

<ComponentPreview name="sidebar-skeleton" />

Render `SidebarMenuSkeleton` in place of menu items while they load.

### Controlled

`SidebarProvider` manages its own open state. Pass `open` and `onOpenChange` to control it.

```tsx
const [open, setOpen] = React.useState(false)

return (
  <SidebarProvider open={open} onOpenChange={setOpen}>
    <Sidebar />
  </SidebarProvider>
)
```

Inside the provider, `useSidebar` reads and changes the same state, such as closing the mobile drawer after navigating.

```tsx
const { isMobile, setOpenMobile } = useSidebar()
```

### Persist the open state

Every toggle writes the open state to a `sidebar_state` cookie. Read it on the server and pass it as `defaultOpen`, so a reload keeps the sidebar the way the user left it. In a Next.js layout:

```tsx
import { cookies } from "next/headers"

import { SidebarProvider } from "@/components/ui/sidebar"

export default async function Layout({
  children,
}: {
  children: React.ReactNode
}) {
  const cookieStore = await cookies()
  const defaultOpen = cookieStore.get("sidebar_state")?.value !== "false"

  return <SidebarProvider defaultOpen={defaultOpen}>{children}</SidebarProvider>
}
```

### Width

Set `--sidebar-width` and `--sidebar-width-icon` on `SidebarProvider` to change the expanded and icon widths.

```tsx
<SidebarProvider
  style={
    {
      "--sidebar-width": "20rem",
      "--sidebar-width-icon": "3.5rem",
    } as React.CSSProperties
  }
>
```

## Design

<DesignGuidelines>

### When to use

- The primary navigation of a product with several top-level sections, such as a dashboard, an admin panel or a tool.

### When not to use

- A panel of actions for specific content. Use a [Drawer](/components/drawer).

### Variants

| Variant | Emphasis | Use for | Not for |
| --- | --- | --- | --- |
| `sidebar` | Medium | Most products. | — |
| `floating` | High | Navigation that stands apart from the content. | Dense tools that need every bit of width. |
| `inset` | Low | Keeping the focus on the content. | Content that's already a set of cards. |

### Guidelines

- Keep the same structure in every view: identity in the header, navigation in the content, account and utilities in the footer.
- Your call: whether the sidebar collapses to icons, hides, or stays open. Pick one and use it consistently. Collapsing to icons needs a clear icon on every item.
- **Header:** the logo, or a workspace switcher that opens a [Dropdown Menu](/components/dropdown-menu). No navigation items.
- **Groups:** add a label once the list gets hard to scan. Keep groups in the same order in every view.
- **Menu items:** one per destination, with an icon and a label of one to three words. Only the current page is active. Nest a sub-menu for child pages worth reaching directly.
- **Item actions:** actions on one item, such as rename or delete, go behind a single [Dropdown Menu](/components/dropdown-menu).
- **Badges:** only for counts or status that need attention, such as unread messages.
- **Footer:** the signed-in user, account actions and rarely used controls such as help.
- **Trigger:** always keep one visible. Your call: where it sits. Keep it in the same place on every screen.

See also: [Menus and navigation](/guidelines/choosing-components#menus-and-navigation) and [Theming](/guidelines/theming).

</DesignGuidelines>

## API Reference

Below 768px, `Sidebar` renders in a [Drawer](/components/drawer). Menu button tooltips use [Tooltip](/components/tooltip).

### SidebarProvider

| Prop | Type | Default |
| --- | --- | --- |
| `defaultOpen` | `boolean` | `true` |
| `open` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |
| `style` | `CSSProperties` | Sets `--sidebar-width` (`16rem`) and `--sidebar-width-icon` (`3rem`) |

### Sidebar

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"left" \| "right"` | `"left"` |
| `variant` | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"offcanvas"` |
| `className` | `string` | — (applied to the panel) |

### SidebarMenuButton

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"ghost" \| "outline"` | `"ghost"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `isActive` | `boolean` | `false` |
| `tooltip` | `string \| TooltipContent props` | — |
| `render` | `ReactElement` | `<button>` |

### SidebarMenuAction

| Prop | Type | Default |
| --- | --- | --- |
| `showOnHover` | `boolean` | `false` |
| `render` | `ReactElement` | `<button>` |

### SidebarMenuSubButton

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "md"` | `"md"` |
| `isActive` | `boolean` | `false` |
| `render` | `ReactElement` | `<a>` |

### SidebarMenuSkeleton

| Prop | Type | Default |
| --- | --- | --- |
| `showIcon` | `boolean` | `false` |

### SidebarGroupLabel and SidebarGroupAction

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `ReactElement` | `<div>` and `<button>` |

### useSidebar

| Property | Type | Description |
| --- | --- | --- |
| `state` | `"expanded" \| "collapsed"` | The desktop sidebar's state |
| `open` | `boolean` | Whether the desktop sidebar is open |
| `setOpen` | `(open: boolean) => void` | Opens or closes the desktop sidebar |
| `openMobile` | `boolean` | Whether the mobile drawer is open |
| `setOpenMobile` | `(open: boolean) => void` | Opens or closes the mobile drawer |
| `isMobile` | `boolean` | Whether the viewport is below 768px |
| `toggleSidebar` | `() => void` | Toggles whichever of the two is showing |

### Subcomponents

| Component | Description |
| --- | --- |
| `SidebarHeader` | Top section of the sidebar |
| `SidebarContent` | Scrollable middle section |
| `SidebarFooter` | Bottom section of the sidebar |
| `SidebarSeparator` | Divider between sections |
| `SidebarInput` | Small input, such as a search field |
| `SidebarGroup` | Logical section within `SidebarContent` |
| `SidebarGroupLabel` | Label for a sidebar group |
| `SidebarGroupAction` | Button pinned to a group's label |
| `SidebarGroupContent` | Body of a group, holds its `SidebarMenu` |
| `SidebarMenu` | List of menu items |
| `SidebarMenuItem` | Single menu item wrapper |
| `SidebarMenuBadge` | Count or status on a menu item |
| `SidebarMenuAction` | Button pinned to a menu item |
| `SidebarMenuSub` | Nested sub-menu container |
| `SidebarMenuSubItem` | Item within a sub-menu |
| `SidebarMenuSubButton` | Link for a sub-menu item |
| `SidebarMenuSkeleton` | Loading placeholder for a menu item |
| `SidebarRail` | Strip along the sidebar's edge that toggles it on click |
| `SidebarTrigger` | Button that toggles the sidebar |
| `SidebarInset` | Main content area next to the sidebar |
