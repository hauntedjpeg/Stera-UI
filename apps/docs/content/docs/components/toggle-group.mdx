## Design

<DesignGuidelines>

### When to use

- Single selection, for mutually exclusive view options, such as switching a list between grid and table layouts or setting text alignment.
- Multiple selection, for independent options in the same category, such as bold, italic and underline in a formatting toolbar.

### When not to use

- Navigation between destinations or sections. Use [Tabs](/components/tabs).
- A choice captured as a form value. Use a [Radio Group](/components/radio-group).

### Guidelines

- Keep the group small, ideally two to five items, and give it a visible or accessible label so the items' shared purpose is clear.
- In single selection, decide whether having nothing selected is valid. If one option must always be active, such as a layout view, pressing the active item shouldn't release it.
- **Items:** give every item in a group the same kind of content: an icon with an accessible label, or a text label of one or two words. Items hold state, not commands, so never use one for a destructive or irreversible action. Use a [Button](/components/button).

See also: [Selection](/design/selection) and [Theming](/design/theming).

</DesignGuidelines>

## API Reference

Built on Base UI's [Toggle Group](https://base-ui.com/react/components/toggle-group#api-reference) and [Toggle](https://base-ui.com/react/components/toggle#api-reference) primitives — see the full API reference there.

### ToggleGroup

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline"` | `"default"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"icon"` |
| `multiple` | `boolean` | `false` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `spacing` | `number` | `0` |
| `disabled` | `boolean` | `false` |

### ToggleGroupItem

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | — |
| `disabled` | `boolean` | `false` |
