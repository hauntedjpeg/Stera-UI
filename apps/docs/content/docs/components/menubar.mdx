## Composition

Use the following composition to build a `Menubar`:

```text
Menubar
├── MenubarMenu
│   ├── MenubarTrigger
│   └── MenubarContent
│       ├── MenubarGroup
│       │   ├── MenubarLabel
│       │   ├── MenubarItem
│       │   │   └── MenubarShortcut
│       │   ├── MenubarCheckboxItem
│       │   └── MenubarRadioGroup
│       │       └── MenubarRadioItem
│       ├── MenubarSeparator
│       └── MenubarSub
│           ├── MenubarSubTrigger
│           └── MenubarSubContent
│               └── MenubarItem
└── MenubarMenu
    ├── MenubarTrigger
    └── MenubarContent
```

## Design

<DesignGuidelines>

### When to use

- An app with enough commands to sort into categories that stay in view, such as File, Edit and View in an editor.

### When not to use

- A few actions tied to one item, such as Edit and Delete on a row. Use a [Dropdown Menu](/components/dropdown-menu).
- Moving between pages or sections. Use a [Sidebar](/components/sidebar) or [Tabs](/components/tabs).
- Finding a command by name. Use a [Command](/components/command), which can sit alongside a Menubar.

### Guidelines

- Name each menu with one word for its category, such as File, Edit or View.
- Items follow the [Dropdown Menu](/components/dropdown-menu) rules: short labels, the `danger` variant for destructive items, and an [Alert Dialog](/components/alert-dialog) to confirm them.
- Show the keyboard shortcut beside every command that has one.
- Disable a command that's unavailable for now instead of removing it, so each menu keeps the same items.
- **Checkbox and radio items:** for settings that stay on or off, such as Show Toolbar, or one choice from a few, such as a panel's position. They hold state, not commands.
- **Submenus:** keep them to one level.

See also: [Menus and navigation](/guidelines/choosing-components#menus-and-navigation) and [Theming](/guidelines/theming).

</DesignGuidelines>

## API Reference

Built on Base UI's [Menubar](https://base-ui.com/react/components/menubar#api-reference) and [Menu](https://base-ui.com/react/components/menu#api-reference) primitives — see the full API references there.

### Menubar

| Prop | Type | Default |
| --- | --- | --- |
| `loopFocus` | `boolean` | `true` |
| `modal` | `boolean` | `true` |
| `disabled` | `boolean` | `false` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

### MenubarItem

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "danger"` | `"default"` |
| `disabled` | `boolean` | `false` |

### Subcomponents

| Component | Description |
| --- | --- |
| `MenubarMenu` | A single menu within the bar; accepts `disabled` to disable it |
| `MenubarTrigger` | Button in the bar that opens its menu |
| `MenubarContent` | Popup panel containing the menu items |
| `MenubarGroup` | Groups related items |
| `MenubarLabel` | Non-interactive section heading |
| `MenubarSeparator` | Horizontal divider |
| `MenubarShortcut` | Right-aligned keyboard shortcut label |
| `MenubarCheckboxItem` | Checkbox-style toggle item |
| `MenubarRadioGroup` | Radio-style selection group |
| `MenubarRadioItem` | Individual radio item |
| `MenubarSub` | Submenu container |
| `MenubarSubTrigger` | Trigger that opens a submenu |
| `MenubarSubContent` | Content panel for a submenu |
