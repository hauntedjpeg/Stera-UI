## Design

<DesignGuidelines>

### When to use

- Setting a value between a defined minimum and maximum, such as volume, price or opacity.
- A range, with two thumbs, when users need both a lower and an upper bound, such as a price filter or a date window.

### When not to use

- When the exact value matters. Pair the slider with an [Input Number](/components/input-number), or use the Input Number alone.

### Guidelines

- Always show the current value, so users know what they've picked.
- Your call: whether the value shows as a persistent label or a tooltip on the thumb. Pick one and use it consistently.

See also: [Forms](/guidelines/choosing-components#forms) and [Theming](/guidelines/theming).

</DesignGuidelines>

## API Reference

Built on Base UI's [Slider](https://base-ui.com/react/components/slider#api-reference) primitive — see the full API reference there.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number \| number[]` | — |
| `defaultValue` | `number \| number[]` | — |
| `onValueChange` | `(value: number \| number[]) => void` | — |
| `onValueCommitted` | `(value: number \| number[]) => void` | — |
| `min` | `number` | `0` |
| `max` | `number` | `100` |
| `step` | `number` | `1` |
| `minStepsBetweenValues` | `number` | `0` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `disabled` | `boolean` | `false` |
| `aria-label` | `string` | — |
| `getAriaLabel` | `(index: number) => string` | — |

`aria-label` and `getAriaLabel` are passed to each thumb's input, which is what screen readers announce. The callbacks receive a `number` when the value is a number and an array when it's an array.
