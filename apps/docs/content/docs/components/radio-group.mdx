## Design

<DesignGuidelines>

### When to use

- Selecting exactly one option from a defined set, such as a payment method or a notification preference.
- Sets small enough to show every option at once, typically two to five.

### When not to use

- Independent choices, where more than one can be selected. Use a [Checkbox](/components/checkbox).
- Long lists of options. Use a [Select](/components/select).

### Guidelines

- Always give the group a visible label that says what the user is choosing. A single radio on its own doesn't explain itself.

See also: [Selection](/design/selection).

</DesignGuidelines>

```text

├── RadioGroupItem
└── RadioGroupItem
```
