## Design

<DesignGuidelines>

### When to use

- Showing the status of an item, such as New, Beta or Active.
- Showing a categorical attribute of an item.

### When not to use

- Actions, or anything the user is expected to interact with. Use a [Chip](/components/chip).

### Guidelines

- Keep labels as short as possible. A single word is ideal.
- Choose the tone for its meaning, so it reinforces the label: `danger` for a destructive or failed status, `success` for a positive one, `warning` for one that needs attention, and `default` for neutral attributes. Your call: what `brand` and `accent` badges mean, and when a badge uses its `-outline` or `-solid` form. Pick one and use it consistently.
- Pair a badge with the thing it describes, such as an [Item](/components/item), an [Avatar](/components/avatar) or an icon. On its own, its meaning is unclear.

See also: [Theming](/design/theming).

</DesignGuidelines>

## Examples

### Variant

Use the `variant` prop to change the style of the badge.

<ComponentPreview name="badge-demo" />

| Variant | Description |
| --- | --- |
| `default` | Subtle neutral background |
| `outline` | Bordered, no background |
| `solid` | Strong neutral inverse background |

### Colors

Appy semantic and brand colors to a badge

<ComponentPreview name="badge-colors" />

| Variant | Description |
| --- | --- |
| `default` | Subtle neutral background |
| `brand` | Primary brand color |
| `accent` | Accent brand color |
| `danger` | Red |
| `success` | Green |
| `warning` | Yellow |

### With Icon

You can render an icon inside the badge. Use data-icon="inline-start" to render the icon on the left and data-icon="inline-end" to render the icon on the right.

<ComponentPreview name="badge-with-icon" />

### With Spinner

You can render a spinner inside the badge. Remember to add the `data-icon="inline-start"` or `data-icon="inline-end"` prop to the spinner.

<ComponentPreview name="badge-with-spinner" />

### Sizes

Use `size` prop to select between `sm` (default), `md`, and `lg`.

<ComponentPreview name="badge-sizes" />

| Size | Description |
| --- | --- |
| `sm` | 16px height (default) |
| `md` | 20px height |
| `lg` | 24px height |

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default"` `"outline"` `"solid"` `"brand"` `"brand-outline"` `"brand-solid"` `"accent"` `"accent-outline"` `"accent-solid"` `"danger"` `"danger-outline"` `"danger-solid"` `"success"` `"success-outline"` `"success-solid"` `"warning"` `"warning-outline"` `"warning-solid"` | `"default"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `render` | `React.ReactElement` | — |

Accepts all standard `<span>` props. Supports `render` prop for polymorphic rendering via Base UI's `useRender`.
