## Design

<DesignGuidelines>

### When to use

- Input likely to run over several lines, such as a message, a description or notes.
- When the line breaks or paragraphs in what the user writes matter to the product.

### When not to use

- Short, structured input, such as a name or an email address. Use an [Input](/components/input).

### Guidelines

- Size it for the expected length of input. A textarea that starts too short tells users to keep it brief.

See also: [Forms](/guidelines/choosing-components#forms).

</DesignGuidelines>

## API Reference

Renders a `<textarea>` element. Uses `field-sizing-content` so the height grows automatically with content. Accepts all standard `<textarea>` props.
