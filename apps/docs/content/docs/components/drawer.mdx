## Composition

Use the following composition to build a `Drawer`:

```text
Drawer
├── DrawerTrigger
└── DrawerPopup
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    ├── DrawerContent       (scrollable region)
    └── DrawerFooter
        └── DrawerClose
```

### Structure

`DrawerPopup` renders two layers. The outer one is an invisible container that sits flush against the screen edge, carries the gutter, and is what slides and drags. The visible panel sits inside it.

```text
DrawerViewport
└── container      (gutter, slides in and out)
    └── panel      (background, radius, shadow)  ← className
```

- `className` styles the panel. Every other prop goes to the container.
- The gutter is the `p-2` on the container in `drawer.tsx`. Change it there and every drawer follows — the animation doesn't depend on it.
- The container hugs the panel, so give side drawers a fixed or viewport-based width (`w-96`, `w-[75vw]`) rather than a percentage.
- State attributes such as `data-swiping` and `data-nested-drawer-open` live on the container. Target them from the panel or its children with `group-data-*/drawer:`.

## Examples

### Bottom Drawer

<ComponentPreview name="drawer-bottom" caption="Bottom Drawer" />

A bottom-anchored drawer renders a drag handle automatically and dismisses on swipe-down.

### Snap points

<ComponentPreview name="drawer-snap-points" caption="Drawer Snap Points" />

Pass `snapPoints` to make a bottom drawer snap between heights. Values can be fractions of the viewport (`0`–`1`), pixel values (`>1` or `"164px"`), or `rem` strings.

### Nested Drawers

<ComponentPreview name="drawer-nested" caption="Nest Drawers" />

Nesting works from any side. A right-anchored drawer tucks its parent toward the edge as the child slides in.

<ComponentPreview name="drawer-nested-side" caption="Nest Side Drawers" />

### Indent

<ComponentPreview name="drawer-indent" caption="Drawer Indent" />

Wrap your app in `DrawerProvider` and place a `DrawerIndentBackground` behind `DrawerIndent`. When any drawer inside the provider opens, the indented content scales back to reveal the background — the iOS-style stacked effect. `DrawerIndent` exposes `--drawer-swipe-progress` (0–1) for swipe-linked motion.

### Swipe to open

<ComponentPreview name="drawer-swipe-area" caption="Drawer Swipe Area" />

Add a `DrawerSwipeArea` — an invisible, fixed strip along the screen edge — so the drawer can be opened by swiping in from that edge on touch devices. Base UI manages the gesture and the strip's `touch-action`; you position it (e.g. `fixed inset-y-0 right-0 w-4`).

## API Reference

Built on Base UI's [Drawer](https://base-ui.com/react/components/drawer#api-reference) primitive — see the full API reference there.

### Drawer

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"right" \| "left" \| "top" \| "bottom"` | `"right"` |
| `swipeDirection` | `"up" \| "down" \| "left" \| "right"` | derived from `side` |
| `snapPoints` | `(number \| string)[]` | – |
| `snapPoint` | `number \| string \| null` | – |
| `onSnapPointChange` | `(snapPoint, details) => void` | – |
| `open` | `boolean` | – |
| `onOpenChange` | `(open, details) => void` | – |
| `modal` | `boolean \| "trap-focus"` | `true` |

### DrawerPopup

| Prop | Type | Default |
| --- | --- | --- |
| `showCloseButton` | `boolean` | `true` |
| `className` | `string` | – (applied to the panel) |

### DrawerTrigger

| Prop | Type | Description |
| --- | --- | --- |
| `render` | `ReactElement` | Render prop for the trigger element |

### DrawerClose

| Prop | Type | Description |
| --- | --- | --- |
| `render` | `ReactElement` | Render prop for the close element |
