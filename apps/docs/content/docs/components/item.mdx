## Design

<DesignGuidelines>

### When to use

- Showing a title and supporting description, paired with media such as an icon, an [Icon Tile](/components/icon-tile), an [Avatar](/components/avatar) or an image.
- Offering actions for a single record, such as a [Button](/components/button) or a [Dropdown Menu](/components/dropdown-menu).

### When not to use

- Collecting input. Use a [Field](/components/field) with an [Input](/components/input), [Radio Group](/components/radio-group), [Checkbox](/components/checkbox) or [Switch](/components/switch).
- Records people need to compare across several attributes. Use a [Table](/components/table).

### Guidelines

- Every item needs a title. Add a description and media only when they help people understand or scan the list.

</DesignGuidelines>

## Composition

Compose `Item` using only the components you need, nested according to this hierarchy:

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemBody
    │   ├── ItemMedia
    │   ├── ItemContent
    │   │   ├── ItemTitle
    │   │   └── ItemDescription
    │   └── ItemActions
    └── ItemFooter
```

## API Reference

### Item

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"outline" \| "subtle" \| "ghost"` | `"outline"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `render` | `ReactElement` | — |

### ItemMedia

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |

### Subcomponents

| Component | Description |
| --- | --- |
| `ItemBody` | Flex row wrapper for media, content, and actions inside an `Item` |
| `ItemContent` | Flex column container for title and description |
| `ItemTitle` | Primary label text |
| `ItemDescription` | Secondary supporting text |
| `ItemActions` | Right-aligned slot for badges, buttons, or controls |
| `ItemGroup` | Wrapper for a list of items |
| `ItemSeparator` | Horizontal divider between items |
| `ItemHeader` | Optional header row for a group |
| `ItemFooter` | Optional footer row for a group |
