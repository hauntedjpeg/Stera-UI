## Design

<DesignGuidelines>

### When to use

- Supplementary content or actions too rich for a [Tooltip](/components/tooltip) but too light for a [Dialog](/components/dialog): filter controls, a short form, a contextual detail view.
- Panels that need interaction, such as buttons, fields or links. For read-only content shown on hover, use a [Preview Card](/components/preview-card).

### When not to use

- Confirmations, or critical decisions that need the user's full attention. Use an [Alert Dialog](/components/alert-dialog).
- Long or complex workflows. Use a [Drawer](/components/drawer) or a [Dialog](/components/dialog).

### Guidelines

- Keep the content focused and short. A popover supplements its trigger; it isn't a place for a workflow.

See also: [Overlays](/design/overlays).

</DesignGuidelines>

## Composition

Use the following composition to build a `Popover`:

```text
Popover
├── PopoverTrigger
└── PopoverContent
    └── PopoverHeader
        ├── PopoverTitle
        └── PopoverDescription
```

## Sides

<ComponentPreview name="popover-sides" caption="Popover Sides" />

| Side | Description |
| --- | --- |
| `top` | Above the trigger |
| `right` | Right of the trigger |
| `bottom` | Below the trigger (default) |
| `left` | Left of the trigger |

## Align

<ComponentPreview name="popover-align" caption="Popover Align" />

| Align | Description |
| --- | --- |
| `start` | Aligned to the start edge of the trigger |
| `center` | Centered on the trigger (default) |
| `end` | Aligned to the end edge of the trigger |

## With Form

<ComponentPreview name="popover-with-form" caption="Popover With Form" />

Popovers can hold interactive content like form fields. Focus moves into the popover when it opens and returns to the trigger when it closes.

## API Reference

Built on Base UI's [Popover](https://base-ui.com/react/components/popover#api-reference) primitive — see the full API reference there.

### Popover

| Prop | Type | Default |
| --- | --- | --- |
| `defaultOpen` | `boolean` | `false` |
| `open` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |

### PopoverTrigger

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `ReactElement` | — |

Use `render` to compose the trigger with another component, such as a `Button`.

### PopoverContent

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `sideOffset` | `number` | `4` |
| `alignOffset` | `number` | `0` |
