## Composition

Use the following composition to build a `Select`:

```text
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    ├── SelectGroup
    │   ├── SelectLabel
    │   ├── SelectItem
    │   └── SelectItem
    ├── SelectSeparator
    └── SelectGroup
        ├── SelectLabel
        ├── SelectItem
        └── SelectItem
```

## Design

<DesignGuidelines>

### When to use

- Choosing from a known, finite set of values, such as a country, a status or a category.
- More options than a [Radio Group](/components/radio-group) or a list of checkboxes handles comfortably, typically more than five.

### When not to use

- Yes-or-no choices. Use a [Checkbox](/components/checkbox) or a [Switch](/components/switch).
- A few options the user should see at once. Use a [Radio Group](/components/radio-group).
- Lists long enough that users need to search them. Use a [Combobox](/components/combobox).

### Guidelines

- Always show a placeholder, such as "Select an option," so it's clear nothing has been chosen yet.
- Keep option labels short and consistently formatted. Don't mix sentence case and title case in one list.

See also: [Forms](/guidelines/choosing-components#forms).

</DesignGuidelines>

## API Reference

Built on Base UI's [Select](https://base-ui.com/react/components/select#api-reference) primitive — see the full API reference there.

### Select

`Select` is an alias for Base UI's `Select.Root`. Accepts all its props.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | — |
| `defaultValue` | `string` | — |
| `onValueChange` | `(value: string) => void` | — |
| `disabled` | `boolean` | `false` |
| `name` | `string` | — |

### SelectTrigger

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |

### SelectContent

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `sideOffset` | `number` | `4` |
| `alignItemWithTrigger` | `boolean` | `true` |

### SelectItem

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | — |
| `disabled` | `boolean` | `false` |
