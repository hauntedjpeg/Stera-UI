## Design

<DesignGuidelines>

### When to use

- A palette opened by a keyboard shortcut, for searching across destinations, actions and settings from anywhere in the product.
- Products with enough commands or destinations that finding them through regular navigation would be slow.

### When not to use

- Actions tied to one item, or in place of inline controls. Use a [Dropdown Menu](/components/dropdown-menu).

### Guidelines

- Show the shortcut that opens it, such as ⌘K, on its trigger so users learn it, and make it work from every screen.
- Write a message for when nothing matches the search, such as "No results found," rather than leaving the list empty.
- **Groups:** cluster related items under a heading, such as Navigation, Settings or Recent, once the list runs past six to eight items. Keep headings to one or two words in sentence case. Don't make a group for a single item: fold it into a neighboring group, or drop the heading.

See also: [Menus and navigation](/design/navigation) and [Theming](/design/theming).

</DesignGuidelines>

## Composition

Use the following composition to build a `Command`:

```text
Command
├── CommandInput
└── CommandList
    ├── CommandEmpty
    ├── CommandGroup
    │   ├── CommandItem
    │   └── CommandItem
    ├── CommandSeparator
    └── CommandGroup
        ├── CommandItem
        └── CommandItem
```

## API Reference

### CommandItem

| Prop | Type | Default |
| --- | --- | --- |
| `disabled` | `boolean` | `false` |

### CommandGroup

| Prop | Type | Description |
| --- | --- | --- |
| `heading` | `string` | Section label shown above the group |

### Subcomponents

| Component | Description |
| --- | --- |
| `CommandInput` | Search/filter text input |
| `CommandList` | Scrollable list container |
| `CommandEmpty` | Shown when no items match the query |
| `CommandSeparator` | Horizontal divider between groups |
| `CommandShortcut` | Right-aligned keyboard shortcut label |
| `CommandItemContent` | Column container for title + description |
| `CommandItemTitle` | Primary text inside `CommandItemContent` |
| `CommandItemDescription` | Secondary text inside `CommandItemContent` |
| `CommandDialog` | Modal wrapper for the command palette |
| `CommandDialogTrigger` | Trigger that opens the `CommandDialog` |
