## Design

<DesignGuidelines>

### When to use

- Short context for elements without a visible label, such as icon buttons or truncated text.
- Keyboard shortcuts next to an action, so users learn them over time. Show them with [Kbd](/components/kbd).

### When not to use

- Information needed to complete a task. Put it inline, or in a component that stays on screen.
- Anything interactive, like links or buttons. Use a [Popover](/components/popover).

### Guidelines

- One short phrase or sentence. A tooltip isn't documentation or a long explanation.

See also: [Overlays](/guidelines/choosing-components#overlays).

</DesignGuidelines>

## API Reference

Built on Base UI's [Tooltip](https://base-ui.com/react/components/tooltip#api-reference) primitive — see the full API reference there.

### TooltipProvider

| Prop | Type | Default |
| --- | --- | --- |
| `delayDuration` | `number` | `700` |

### TooltipContent

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"top"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `sideOffset` | `number` | `4` |
| `alignOffset` | `number` | `0` |

### TooltipTrigger

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
