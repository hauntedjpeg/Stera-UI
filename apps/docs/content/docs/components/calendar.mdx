## Design

<DesignGuidelines>

### When to use

- Picking a single date, such as an appointment, a due date or an event date.
- Picking a start and end date, such as a booking window or a reporting period.

### Guidelines

- When the date is likely to be far from today, such as a birth date, offer a faster way to jump to a month and year than stepping through months one at a time.
- Disable the dates users can't pick.

See also: [Forms](/guidelines/choosing-components#forms), [Theming](/guidelines/theming).

</DesignGuidelines>

## API Reference

`Calendar` takes every [react-day-picker](https://daypicker.dev/) prop. These are the ones you'll reach for most, plus the props Stera UI adds or changes.

| Prop              | Type                                                             | Default   |
| ----------------- | ---------------------------------------------------------------- | --------- |
| `mode`            | `"single" \| "multiple" \| "range"`                              | —         |
| `selected`        | `Date \| Date[] \| DateRange`                                    | —         |
| `onSelect`        | `(value) => void`                                                | —         |
| `required`        | `boolean`                                                        | `false`   |
| `disabled`        | `Matcher \| Matcher[]`                                           | —         |
| `numberOfMonths`  | `number`                                                         | `1`       |
| `captionLayout`   | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"label"` |
| `showOutsideDays` | `boolean`                                                        | `true`    |
| `showWeekNumber`  | `boolean`                                                        | `false`   |
| `buttonVariant`   | Button `variant`                                                 | `"ghost"` |
| `classNames`      | `Partial<ClassNames>`                                            | —         |

- Without `mode`, the calendar only displays dates. In `single` mode, clicking the selected date clears it unless `required` is set.
- `showOutsideDays` defaults to `true`, unlike react-day-picker.
- `buttonVariant` styles the previous and next month buttons.
- `classNames` is merged with the Stera UI classes slot by slot, so `classNames={{ day: "…" }}` adds to the day cell's styles instead of replacing them.
- For custom day content, pass `components={{ DayButton }}` and render `CalendarDayButton`, which the file also exports.
