## Design

<DesignGuidelines>

### When to use

- Picking a single date, such as an appointment, a due date or an event date.
- Picking a start and end date, such as a booking window or a reporting period.

### Guidelines

- When the date is likely to be far from today, such as a birth date, offer a faster way to jump to a month and year than stepping through months one at a time.
- Disable the dates users can't pick.

See also: [Theming](/design/theming).

</DesignGuidelines>

## API Reference

`Calendar` extends all props from [react-day-picker](https://react-day-picker.js.org/).

| Prop | Type | Default |
| --- | --- | --- |
| `mode` | `"single" \| "range" \| "multiple"` | `"single"` |
| `selected` | `Date \| DateRange \| Date[]` | — |
| `onSelect` | `(value) => void` | — |
| `disabled` | `Date[] \| Matcher` | — |
| `captionLayout` | `"label" \| "dropdown"` | `"label"` |
| `showWeekNumber` | `boolean` | `false` |
