## Design

<DesignGuidelines>

### When to use

- Selecting and deselecting options in a set, such as filters or categories.
- Representing an input the user created, such as a contact or a tag, especially one they can remove.

### When not to use

- Showing a status or attribute that isn't interactive. Use a [Badge](/components/badge).

### Guidelines

- Keep labels short, ideally one to three words.
- If a chip can be removed, put the remove action in the chip itself.

See also: [Theming](/design/theming).

</DesignGuidelines>

## API Reference

Built on Base UI's [Button](https://base-ui.com/react/components/button#api-reference) primitive — see the full API reference there. Renders as a `<button>` element.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"subtle" \| "outline" \| "solid"` | `"subtle"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"xs"` |
| `active` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
