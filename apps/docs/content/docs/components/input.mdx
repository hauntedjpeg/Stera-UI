## Design

<DesignGuidelines>

### When to use

- Short, freeform text, such as a name, an email address or a search query.

### When not to use

- Longer or multi-line input. Use a [Textarea](/components/textarea).
- A prefix, a suffix or an action tied to the value, such as a currency symbol or a Copy button. Use an [Input Group](/components/input-group).
- A choice from a known set of values. Use a [Select](/components/select).
- A fixed-length code sent to the user, such as a one-time password. Use an [Input OTP](/components/input-otp).
- An exact number, such as a quantity. Use an [Input Number](/components/input-number).

### Guidelines

- Always pair an input with a visible label. A placeholder isn't a label: it disappears as soon as the user starts typing.

See also: [Forms](/design/forms).

</DesignGuidelines>

## API Reference

Built on Base UI's [Input](https://base-ui.com/react/components/input#api-reference) primitive — see the full API reference there. Accepts all standard `<input>` props except `size`.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `type` | `string` | `"text"` |
