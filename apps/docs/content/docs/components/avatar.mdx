## Design

<DesignGuidelines>

### When to use

- Representing a specific user, account or entity next to their name or other identifying information, such as in an [Item](/components/item), a comment thread or a navigation header.
- Representing a set of people, such as team members or conversation participants, as a group.

### Guidelines

- Use an avatar only to stand for a person or entity, never as decoration.
- Always provide a fallback: the person's initials, or a generic person icon if there are no initials to show, so an avatar never renders empty or broken.
- **Status badge:** shows presence or state, such as online, away or busy. Use it sparingly, only where presence is genuinely useful to the user. Your call: which badge variant marks which status. Pick one and use it consistently.
- **Groups:** for shared ownership or participation, such as the members of a project, a task or a conversation. Keep the visible avatars to a few, typically three to five, and add an overflow count of the members not shown. A group is a summary, not a member list: when the full list matters, link to it or show it alongside.

</DesignGuidelines>

## Composition

Use the following composition to build an `Avatar`:

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

Use the following composition to build an `AvatarGroup`:

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

| Prop | Type | Default |
