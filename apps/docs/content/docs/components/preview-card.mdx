## Composition

Use the following composition to build a `PreviewCard`:

```text
PreviewCard
├── PreviewCardTrigger
└── PreviewCardContent
```

## Sides

<ComponentPreview name="preview-card-sides" />

| Side | Description |
| --- | --- |
| `top` | Above the trigger |
| `right` | Right of the trigger |
| `bottom` | Below the trigger (default) |
| `left` | Left of the trigger |

## Delay

<ComponentPreview name="preview-card-delay" />

Use `delay` and `closeDelay` on `PreviewCardTrigger` to control when the card opens and closes.

## Design

<DesignGuidelines>

### When to use

- A richer preview of a linked person, document or entity, such as a user's profile when hovering their name in a list or comment thread.
- Context that helps users decide whether to navigate, without committing to a full page visit.

### When not to use

- Content that needs an action or response. Use a [Popover](/components/popover) or a [Dialog](/components/dialog).

### Guidelines

- Keep it brief and scannable: a summary, not a detail view. A title, a short supporting detail and optional metadata is usually enough.
- Never put interactive controls, like buttons or forms, inside it. Use a Popover instead.

See also: [Overlays](/guidelines/choosing-components#overlays).

</DesignGuidelines>

## API Reference

Built on Base UI's [Preview Card](https://base-ui.com/react/components/preview-card#api-reference) primitive — see the full API reference there.

### PreviewCard

| Prop | Type | Default |
| --- | --- | --- |
| `defaultOpen` | `boolean` | `false` |
| `open` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |

### PreviewCardTrigger

| Prop | Type | Default |
| --- | --- | --- |
| `delay` | `number` | `600` |
| `closeDelay` | `number` | `300` |
| `render` | `ReactElement` | — |

### PreviewCardContent

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |

| `sideOffset` | `number` | `4` |
| `alignOffset` | `number` | `4` |
