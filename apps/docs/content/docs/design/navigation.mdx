| Use                                        | For                                                         | Holds                    |
| ------------------------------------------ | ----------------------------------------------------------- | ------------------------ |
| [Dropdown Menu](/components/dropdown-menu) | Related actions behind one trigger, often for one item      | Actions or options       |
| [Command](/components/command)             | Searching for anything in the product from the keyboard     | Actions and destinations |
| [Sidebar](/components/sidebar)             | The product's primary navigation between top-level sections | Destinations             |
| [Breadcrumb](/components/breadcrumb)       | Showing where a nested page sits, and going back up         | Parent destinations      |

## Deciding

Work down the list and stop at the first yes.

1. Is it a set of actions tied to one item or area, such as Edit and Delete on a row? Use a Dropdown Menu.
2. Is it a way to search for any action or destination across the product? Use a Command.
3. Is it the product's primary navigation between top-level sections? Use a Sidebar.
4. Is the page nested, with users who need to see where they are and get back to its parents? Use a Breadcrumb.

A choice that's part of a form isn't a menu. See [Forms](/design/forms).

## Shared rules

- **Group headings are short labels.** One or two words in sentence case, such as Settings or Recent, in a Command or a Sidebar.
- **No single-item groups.** Fold the item into a neighboring group, or drop the heading.
- **Destinations and actions stay apart.** Sidebar items go somewhere; actions belong in a Dropdown Menu or a [Button](/components/button). A Command can hold both.
